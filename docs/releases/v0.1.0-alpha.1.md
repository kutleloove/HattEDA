# HattEDA 0.1.0-alpha.1 — Developer Preview

This is the first public development preview of HattEDA. It is intended for evaluation and issue
reports, not unattended production use. Always inspect generated Gerber and drill files in an
independent viewer before manufacturing a board.

## Highlights

- Mergen schematic editor and Kayra PCB/CAM workspace.
- Project save, autosave, recovery, backup and lock files.
- Schematic connectivity, PCB transfer, ratsnest, ERC and DRC.
- Net classes, two copper layers, pads, vias, copper zones and keepouts.
- Gerber X2, Excellon, BOM, pick-and-place, CAM preview and print/PDF layout.
- In-app Auto Router controls backed by bundled Freerouting 2.4.1 and a private Java runtime.
- Real-dimension 0402–2512 chip footprints and improved axial diode silkscreen.
- Turkish and English interface.

## Known limitations

- Auto Router currently accepts one closed Board Edge and an unrouted board without existing
  tracks, vias or zones. Multi-board autorouting is not implemented yet.
- Auto placement is deterministic and constrained to Board Edge regions, but is not yet optimized
  for shortest total ratsnest length.
- Nonlinear device solver work exists in the electrical core but is not fully connected to every
  catalog component in the application UI.
- Several footprint families still use provisional geometry and rectangular silkscreen.
- The `.hatt` project format is versioned but may change before the stable release.
- Manual editor QA is still in progress; please attach the smallest reproducing `.hatt` file and a
  screenshot to bug reports.

## Included third-party software

The Windows bundle contains Freerouting 2.4.1 and Eclipse Temurin JRE 25.0.4.1+1. Licenses and
notices are included in the archive. The corresponding Freerouting source archive is published as
a separate asset on this release page.
